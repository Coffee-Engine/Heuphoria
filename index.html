What is Heuphoria?

Heuphoria is a library meant to take some tedium out of colour management in projects. It's name is a mixture of Euphoria and Hue because that is kind of funny.

What is added in Heuphoria?

It comes with one new object type which would be Color which contains multiple helpful tools for colour management in javascript.
